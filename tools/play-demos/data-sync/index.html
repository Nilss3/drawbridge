Downloading a file

app.drawbridge.heraldmono · FOREGROUND_SERVICE_DATA_SYNC

The download starts because the user taps it, and nothing else starts one. While it runs, herald holds a foreground service so the transfer survives the browser going to the background, and posts the notification that shows its progress.

Download the sample file 12 MB — deliberately slow, so the progress is visible
  1. Tap the link above.
  2. Confirm the download.
  3. The notification shows it running, then finished.
  4. The file is in herald's own Downloads list.
Without the service, a download would be killed the moment the browser stopped being the app on screen.
