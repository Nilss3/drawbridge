# DRAFT default whitelist -- app_ratings.allowed_packages
#
# Every entry here is a package the rating rule would otherwise REMOVE (Parental
# guidance, or PEGI 7+) that a household plausibly needs. Drafted 2026-08-17 from
# the two corpus runs in this directory; see docs/app-ratings.md.
#
# Two standing rules, both checkable:
#   1. Nothing here may appear in blocked_packages. The whitelist is evaluated
#      BEFORE the blocklist, so an overlap silently unblocks a blocked app.
#   2. Nothing here may be governed by an option. WhatsApp and Telegram are
#      deliberately absent: whitelisting them would override the parent's switch
#      and make the option a decoration.

# --- music and audiobooks -----------------------------------------------------
# Not video: long-form streaming has its own option, and this list must never
# reach into a category a switch already governs. Every one of these is Parental

# is ungraded content and therefore the band, whatever the music is.
#
# YouTube Music is deliberately absent and is the sharpest case in this file:
# it is Parental guidance like the rest, and it is exempted by *Allow YouTube*.
# Whitelisting it would override that switch, and policytool.py sign refuses the
# document for exactly that reason — it also names blocked_packages, so the
# refusal fires twice.
